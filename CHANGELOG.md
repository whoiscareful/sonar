# Changelog · 更新日志

All notable source and package changes are recorded here.
此文件记录主要源码与安装包变更。

## 1.0.0 — 2026-07-16

### English

- Established the first versioned HeartTone source release.
- Added favorite, frequent, recent, random, and newest music feeds with server favorite synchronization.
- Added local playlist management, multi-select actions, artwork, import matching, OCR import, and platform-share-link import.
- Added full-screen lyrics with optional Music Tag Web enrichment and Subsonic fallback.
- Added listening statistics, recent history, sleep timer, personalization, and granular data management.
- Added user-data backup and restore for configuration, playlists, listening history, appearance, and cache preferences.
- Improved album, library, now-playing, foldable outer-screen, caching, and background playback experiences.
- Moved server passwords and optional API tokens to HarmonyOS Asset Store.
- Removed local signing configuration from version control and published an unsigned HAP with a SHA-256 checksum.

### 中文

- 建立 HeartTone 首个正式版本化源码发布。
- 新增收藏、常听、最近、随机和最新音乐分类，并支持服务器收藏同步。
- 新增本地歌单、多选操作、封面、导入匹配、截图 OCR 和平台分享链接导入。
- 新增全屏歌词，并支持可选 Music Tag Web 增强与 Subsonic 回退。
- 新增听歌统计、最近播放、睡眠定时、个性化配置和细粒度数据管理。
- 新增用户数据备份与恢复，覆盖配置、歌单、听歌记录、外观和缓存偏好。
- 改进专辑、媒体库、正在播放、折叠屏外屏、缓存和后台播放体验。
- 将服务器密码和可选 API Token 迁移到 HarmonyOS Asset Store。
- 从版本控制中移除本机签名配置，并发布带 SHA-256 校验值的 unsigned HAP。
